# Fintech Mobile — Interface Web

Projeto de interface web com temática financeira, desenvolvido utilizando HTML5 e CSS3.

## Sobre o projeto

Aplicação front-end criada para praticar estruturação de páginas web, estilização de componentes e desenvolvimento de interfaces.

O projeto utiliza uma estrutura simples, com arquivos HTML, CSS e recursos visuais organizados na pasta `assets`.

## Tecnologias

- HTML5
- CSS3

## Estrutura do projeto

```text
projetoFintech-mobile/
├── assets/
└── index.html
```

## Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Explore a interface.
